# Poultry Management System - Backend

Backend REST API developed using FastAPI for the Poultry Management System. The application provides secure APIs for authentication, poultry management, dashboard analytics, inventory tracking, and report generation.

## 🚀 Features

- REST APIs
- MongoDB Integration
- Dashboard Analytics APIs
- User Management
- Bird Management
- Inventory APIs
- Batch Management

## 🛠 Tech Stack

- FastAPI
- Python
- MongoDB
- Uvicorn

## Project Structure

```
app/
 ├── routers/
 ├── models/
 ├── schemas/
 ├── services/
 ├── database/
 └── utils/
```

## Installation

```bash
git clone <repository-url>

cd poultry-backend

pip install -r requirements.txt
```

The server starts at

```
http://127.0.0.1:8000
```

Swagger Documentation

```
http://127.0.0.1:8000/docs
```
